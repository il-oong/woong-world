## 등록 방법

`src/data/plugins.json`에 항목 추가.

```json
{
  "id": "plugin-id",
  "name": "표시 이름",
  "description": "설명",
  "repo": "il-oong/repo-name",   // GitHub 레포 (CI 상태 조회용)
  "branch": "main",
  "pr": null,                    // PR 번호 (개발 중이면 지정)
  "path": null,                  // 내부 경로 (woong-world 내부 앱이면)
  "url": "https://...",          // 외부 배포 URL (별도 앱이면)
  "embeddable": true,            // iframe 임베드 가능 여부
  "accent": "#색상코드",
  "tags": ["태그1", "태그2"]
}
```

## 현재 플러그인

| ID | 이름 | 타입 | 상태 |
|----|------|------|------|
| `ai-idea-note` | AI 아이디어 노트 | 외부 레포 | 🟡 개발 중 |
| `todo` | 할 일 | 내부 앱 (`/apps/todo`) | 🟢 운영 중 |

---

## 플러그인 타입 구분

### A. 내부 앱 (path 방식)
- woong-world 레포 안에 `/apps/{id}` 폴더로 개발
- `path: "/apps/todo"` 처럼 경로 지정
- 빌드가 함께 됨 → 가볍지만 배포 결합도 높음

### B. 외부 앱 (url 방식)
- 별도 레포, 별도 Vercel 배포
- `url: "https://my-plugin.vercel.app"` 지정
- iframe으로 임베드
- 무거운 기능에 적합, 독립 배포 가능
