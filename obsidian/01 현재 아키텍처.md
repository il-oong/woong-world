# 현재 아키텍처

> [[00 woong-world]]의 기술 구조

---

## 스택

| 항목 | 내용 |
|------|------|
| 프레임워크 | Next.js 16.2 (App Router) |
| 언어 | TypeScript |
| 배포 | Vercel |
| 저장소 | Upstash Redis + Vercel Blob |
| 인증 | Google OAuth + Jose JWT 쿠키 |
| AI | Google Gemini 2.5-flash-lite |

---

## 데이터 흐름

```
AI 어시스턴트
  클라이언트 → /api/assistant/chat
    → lib/gemini.ts (캘린더/플랜/플러그인 컨텍스트 주입)
    → Redis (대화 기록)

캘린더
  lib/session.ts (JWT) → lib/google.ts (OAuth) → /api/google/events

플랜
  /api/plans → lib/plans.ts → Redis

파일
  Vercel Blob (파일) + Redis (메타데이터)
```

---

## 컴포넌트 트리

```
layout.tsx
├── TopNav.tsx          ← 전역 네비 (admin: 웅허브 + /plugins)
└── AssistantWidget.tsx ← 플로팅 AI 버튼
    └── AssistantPanel.tsx

page.tsx (홈)
├── BriefingPlayer
├── CalendarWidget
└── HubGrid             ← admin 전용, 플러그인 카드

plugins/[id]/page.tsx   ← admin 전용
└── PluginEmbed         ← iframe 또는 외부 링크
```

---

## Redis 키 네임스페이스

| 키 패턴 | 용도 |
|---------|------|
| `chat:{sessionId}` | AI 대화 기록 |
| `files:{sessionId}` | 업로드 파일 메타 |
| `plans:{userId}` | 목표/플랜 |

## 보안

- CSP는 `next.config.ts`에서 관리
- 새 외부 리소스 추가 시 CSP 도메인 허용 필수
- admin 게이팅: `lib/admin.ts` → `isAdminSession()`
