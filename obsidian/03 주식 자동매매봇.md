# 주식 자동매매봇 플러그인

> [[02 플러그인 시스템]]의 외부 앱(B타입) 플러그인.  
> 기존 자동매매 레포를 woong-world 허브에서 iframe으로 조작.

---

## 목표

- 기존 레포의 **기획서/전략 문서**를 woong-world 플러그인 페이지에서 열람
- 봇 상태(활성/중지), 최근 체결, 수익률 등 **대시보드** 조회
- woong-world AI 어시스턴트에서 매매 결과를 **브리핑**받을 수 있는 연결점

---

## 연동 방식

```
기존 자동매매 레포 (별도 Vercel 배포)
  ↓ iframe embed
plugins/stock-bot/page.tsx (woong-world)
  ↑ plugins.json에 url + repo 등록
```

---

## plugins.json 등록 예시

```json
{
  "id": "stock-bot",
  "name": "주식 자동매매봇",
  "description": "자동 매매 전략 실행 및 수익률 모니터링",
  "repo": "il-oong/stock-bot",
  "branch": "main",
  "pr": null,
  "url": "https://stock-bot.vercel.app",
  "embeddable": true,
  "accent": "#fbbf24",
  "tags": ["주식", "자동화", "금융"]
}
```

---

## 해야 할 일

- [ ] 기존 레포 URL 확인 및 Vercel 배포 확인
- [ ] 기획서 마크다운을 이 노트 하위 노트로 이식 (`[[주식봇 기획서]]`)
- [ ] iframe 허용 헤더 설정 (X-Frame-Options)
- [ ] AI 어시스턴트 컨텍스트에 봇 상태 API 연결 (선택)

---

## 참고: iframe 허용 설정

기존 레포의 `next.config.ts`에 아래 추가 필요:
```ts
headers: [{ key: "X-Frame-Options", value: "ALLOW-FROM https://woong-world.vercel.app" }]
// 또는 CSP frame-ancestors 방식 권장
```
