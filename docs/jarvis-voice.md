# JARVIS 음성 대화 모드

챗 패널의 🎤 버튼을 누르면 **듣기 → 답변 생성 → 소리로 읽기 → 다시 듣기** 를 손 안 대고 반복한다.

```
🎤 → 브라우저 음성 인식(ko-KR) → /api/assistant/chat → 답변
   → /api/assistant/speak (Google TTS, 비서 목소리) → 재생 → 다시 듣기
```

## 동작
- 말이 끝나면 자동으로 전송된다. "그만", "종료", "끝", "대화 종료" 라고 말하면 모드가 꺼진다.
- 무음이 3번 연속이면 자동 종료된다. 화면의 `대화 종료` 버튼으로도 끌 수 있다.
- 답변에 승인 카드(일정 추가, 개발 요청 등)가 있으면 "승인이 필요한 항목이 화면에 있어요"라고만 말한다. **승인과 머지는 항상 화면 버튼으로** 한다. 음성으로는 실행되지 않는다.
- 읽을 때 코드 블록, 링크, 마크다운은 정리된다. 길이는 1,200자까지.

## 구성
| 파일 | 역할 |
|---|---|
| `src/components/useVoiceChat.ts` | 듣기/말하기 상태 머신 (Web Speech API) |
| `src/components/AssistantPanel.tsx` | 🎤 버튼, 상태 표시줄(듣는 중/생각 중/말하는 중) |
| `src/app/api/assistant/speak/route.ts` | 로그인 사용자 전용 TTS, 분당 30회 제한 |
| `next.config.ts` | `Permissions-Policy` 를 `microphone=(self)` 로 변경 (기존엔 마이크 전체 차단) |

## 요구사항과 한계
- 음성 인식은 **Chrome/Edge(데스크톱·안드로이드)** 와 Safari 일부에서 동작한다. 지원하지 않는 브라우저에서는 🎤 버튼이 보이지 않는다.
- 음성 인식은 브라우저가 Google 서버로 음성을 보내 처리한다(브라우저 기능). 서버에는 인식된 글자만 전달된다.
- `GOOGLE_TTS_API_KEY` 가 없거나 TTS가 실패하면 브라우저 내장 음성(speechSynthesis)으로 대신 읽는다.
- "자비스야" 같은 호출어로 항상 듣는 기능은 웹에서 불가능하다. 화면을 켜고 🎤 를 누르는 방식이다.
- iOS Safari는 사용자 터치 직후가 아니면 오디오 자동 재생이 막힐 수 있어 첫 응답이 브라우저 음성으로 나올 수 있다.
