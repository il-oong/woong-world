# 계정별 사용과 관리자 권한

방문자는 사이트에서 자신의 Google 계정으로 로그인합니다. 일정은 로그인한 계정의 Google Calendar에서 읽고, 비서 설정·계획·메모·투자 기록·청약 내 정보와 관심 공고는 로그인 이메일별 Redis 키에 저장합니다. 홈 화면 위젯의 순서·숨김 설정도 이제 계정별로 저장되어 다른 브라우저에서 로그인해도 이어집니다. 이전 브라우저의 공용 위젯 설정은 기본 관리자 계정에 한 번만 이전합니다.

상단 왼쪽의 **허브**는 모든 사용자에게 보입니다. 일반 사용자는 플러그인·관리자·옵시디언 메뉴를 보지 못하며, 주소를 직접 열어도 서버에서 관리자 권한을 검사합니다. 추가 관리자는 플러그인과 내부 관리자 기능을 사용할 수 있습니다. **관리자** 화면에서 다른 사람의 권한을 지정하거나 해제하는 일은 `ADMIN_EMAIL`에 설정한 기본 관리자만 할 수 있습니다. 기본 관리자 이메일은 공개 상태 API에 표시하지 않습니다.

관리자 지정: 기본 관리자 계정으로 로그인 → **관리자** → 상대방의 Google 로그인 이메일을 입력하고 추가합니다. 상대방이 해당 계정으로 로그인하면 권한이 적용됩니다. 관리자 목록은 Redis에 저장되므로 `UPSTASH_REDIS_REST_URL`과 `UPSTASH_REDIS_REST_TOKEN`이 필요합니다. 기본 관리자 `ADMIN_EMAIL`은 Vercel 환경 변수에서 관리합니다.

다른 Google 계정이 로그인할 수 있는지는 Google Cloud Console의 **Google 인증 플랫폼 → 대상(Audience)** 설정에도 달려 있습니다. 외부 앱이 **테스트** 상태라면 등록된 테스트 사용자만 접근할 수 있습니다. 누구나 Google 계정으로 쓰도록 공개하려면 대상이 **외부**이고 게시 상태가 **프로덕션**이어야 합니다. 현재 로그인은 Google Calendar 읽기·쓰기 범위를 요청하므로 Google의 앱 확인 절차가 필요할 수 있습니다. 이 콘솔 설정은 코드 배포만으로 변경되지 않습니다.
