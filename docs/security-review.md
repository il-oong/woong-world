# 2026-10-01 보안 점검

이번 점검에서 주식 AI 분석, 일정 CSV 미리보기, Google 시트 가져오기, 푸시 알림 변경 API에 로그인 확인이 빠져 있었습니다. 로그인한 사용자만 호출하도록 수정했습니다. Google 시트 가져오기는 Google이 관리하는 HTTPS 주소로만 이동하고 응답 크기를 2MB로 제한합니다. 알림 수정은 서버에 저장된 소유자 이메일과 현재 로그인 계정이 같을 때만 허용합니다.

로그아웃 시 아이폰 단축어용 브리핑 토큰을 폐기합니다. 기존 단축어를 다시 쓰려면 로그인 후 새 URL을 복사해야 합니다. 문서·PDF·텍스트 첨부는 더 이상 공개 Blob 저장소에 중복 업로드하지 않으며, 새로운 이미지·음성 URL에는 계정 이메일이나 원본 파일 이름을 넣지 않습니다. 이미지 업로드는 PNG·JPEG·WebP·GIF와 5MB 이하로 제한합니다.

**남은 배포 설정:** 현재 이미지 첨부와 생성된 음성 브리핑은 공개 Vercel Blob 저장소에 저장됩니다. URL을 알면 로그인 없이 볼 수 있으므로 민감한 이미지는 올리지 않는 것이 안전합니다. 완전한 비공개 저장을 하려면 별도의 Private Blob 저장소를 연결하고, 인증된 다운로드 경로로 전환한 뒤 기존 공개 파일을 삭제해야 합니다. 기존 공개 파일은 코드 변경만으로 비공개가 되지 않습니다.

Google OAuth가 외부 사용자에게 공개됐는지도 Google Cloud Console에서 확인해야 합니다. 코드의 로그인·권한 검사와 별개인 운영 설정입니다.

**공개 전 사용량 보호:** Google 계정으로 가입하는 사용자가 늘면 AI·음성 API 사용량도 늘어납니다. 현재 앱 전체에 통합된 일일 사용량 상한이 없으므로, 외부 사용자 공개 전에 API 제공자의 예산 한도와 앱의 사용자별·전체 요청 한도를 설정하는 것이 좋습니다.
