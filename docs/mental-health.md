# 마음결: 심리치료 탭의 AI 자기관리 기능

## 사용자 흐름

상단의 **지금 불안해요** 버튼은 ‘순간 도움’을 연다. 저장된 기록을 불러오는 중에도 짧은 감각 알아차리기 안내는 이용 가능하다. 상황 선택/한 줄 설명→현재 상황에만 맞춘 짧은 AI 대화→다음 행동 선택 순서이며 원하는 부분만 이용할 수 있다. 시작/마무리 불안 점수는 선택 사항이고 낮아지지 않아도 실패로 평가하지 않는다.

순간 도움의 AI 전송은 별도 동의가 필요하며 이번 상황·점수·이번 대화만 포함한다. 기존 대화나 사용자 기억을 자동으로 보내지 않는다. 응답 기다리기를 중단할 수 있지만 이미 전송한 데이터는 회수되지 않는다. 이 모드의 대화 원문은 화면에서만 유지되고 암호화 저장에도 포함하지 않는다. 사용자가 ‘이번 상황을 내 기록에 추가’를 누를 때만 상황·점수·선택한 행동을 실천 기록에 반영한다. 같은 상황을 수정하면 중복 추가하지 않으며 보고서에서도 확인할 수 있다.

기본 안내는 네트워크/모델 없이 화면에 표시된다(앱 페이지 자체를 오프라인에서 새로 여는 기능은 아님). 갑작스러운 심한 신체 증상을 불안으로 단정하지 않고 응급 도움을 우선하며, 반복적인 확신 요구나 실제 위험 상황에서 확인 미루기를 강요하지 않도록 AI 지침을 분리했다.

/therapy에서 로그인한 사용자만 접근한다. 오늘 기분(높을수록 좋음)과 불안(높을수록 강함)을 0~10으로 기록하고, CBT 사고기록 및 작은 활동/확인 미루기/감정 전달 연습을 작성한다. 대화 AI는 실제 치료사가 아니며 학위·경력·진단·치료 효과를 주장하지 않는다.

기록은 기본적으로 React 화면 메모리에만 존재한다. 새로고침/페이지 이동 전에 사용자가 선택적으로 암호화 저장하거나 보고서를 다운로드한다. 로컬 영구 저장, 자동 저장, 푸시 알림, 일반 비서·옵시디언 연동은 없다.

## 운영 설정

- 기존 Google 로그인 및 Redis 설정을 사용한다.
- MENTAL_HEALTH_ENCRYPTION_KEY: 암호학적으로 무작위 생성한 32바이트를 64자리 hex로 설정한다. 다른 키와 재사용하지 않는다. 유실하면 기존 기록을 읽을 수 없으며 교체 시 별도 마이그레이션이 필요하다.
- GEMINI_API_KEY: 기존 서버 측 Gemini 키.
- MENTAL_HEALTH_AI_PRIVACY_REVIEWED=true: 운영자가 해당 프로젝트의 유료 서비스 적용 여부, 민감정보 처리 적합성, 보관·삭제 조건을 확인한 뒤에만 설정한다. 코드가 유료 계정을 자동 검증하는 것은 아니다. Google의 무료 서비스에는 민감정보를 보내지 않는다.
- MENTAL_HEALTH_MODEL: 선택. 기본값은 기존 앱과 같은 gemini-2.5-flash. 배포 시 해당 계정의 모델 가용성을 확인한다.
- 키가 없으면 암호화 저장을 비활성화한다. 개인정보 검토 플래그가 없으면 외부 AI 호출을 차단한다. 자동 대체 제공사나 로컬 가짜 AI 응답은 없다.
- 실제 배포, 유료 계정 활성화, 운영 비밀키 변경은 이 PR에서 수행하지 않는다.

## 개인정보와 안전 경계

- 모든 API는 암호화된 로그인 세션을 확인한다. 클라이언트의 계정 바인딩 헤더로 열린 탭에서 계정이 바뀐 경우 저장/전송을 거부한다. 사용자별 소유권은 서버의 세션 이메일로 결정한다.
- 쓰기 및 AI 요청은 동일 출처 검사, 엄격한 스키마, 실제 요청 바이트 한도 256KB를 적용한다.
- AES-256-GCM 무작위 nonce, 사용자 키를 AAD로 바인딩. Redis 키는 전용 키로 이메일을 HMAC 처리한다. 앱 운영자는 키를 가지고 있으므로 종단간 암호화가 아니다.
- 저장은 명시적 버튼으로만 수행하고 마지막 저장 후 30일 TTL. 오래된 탭의 쓰기는 원자적 revision 비교로 거부한다.
- 삭제는 암호문을 즉시 제거하고 민감정보가 없는 revision tombstone만 30일 유지해 오래된 저장이 기록을 되살리지 못하게 한다. 삭제 후 자동 재저장은 없다.
- 운영 백업과 호스팅 로그의 보관은 별도 정책이다. 요청/응답 본문을 APM·리버스 프록시·에러 수집기에 기록하지 않도록 배포 환경을 검토한다.
- 대화 최대 24개 및 사용자가 선택한 기억/오늘 기록만 AI에 전송한다. 보고서는 별도 편집 가능한 전송 미리보기를 거친다. 계정 이메일은 AI 요청에 넣지 않는다.
- 보고서 다운로드는 TXT/정적 HTML. HTML은 모든 사용자·모델 텍스트를 escape하고 스크립트/네트워크를 CSP로 차단한다. 파일을 열어 브라우저 인쇄로 PDF 저장 가능. 내려받은 파일은 암호화되지 않는다.
- 보고서 원문에는 선택 기간의 기분/사고/실천 기록이 포함된다. 대화·기억은 제외. AI 분석은 임시 화면 데이터이며 날짜나 기록을 바꾸면 무효화한다.
- AI 요청은 사용자당 분당 12회. 모델 타임아웃 40초, 실패 응답은 고정 오류로 처리하여 제공사 본문의 민감정보가 노출되지 않는다.
- 위기 키워드 탐지는 추가적인 보수적 안전장치이며 임상 분류기가 아니다. 오탐/누락 가능. 시스템 지침에서도 위기·폭력 상황에는 분석을 중단하고 현재 안전 확인과 사람의 도움을 우선한다.
- 항상 열 수 있는 긴급 도움 안내가 있다. 실시간 모니터링/구조 요청을 제공하지 않는다. 한국 109 연락처는 구현일에 전용 지역 도움 도구로 확인했다. 다른 국가 번호를 추측하지 않는다.
- 운영 전 정신건강 전문가의 대화 시나리오 검토를 권장한다. 모델 안전 행동은 프롬프트나 키워드만으로 보장할 수 없다.

## 검증

npx tsx --test tests/mental-health.test.ts

순간 도움을 포함한 기능 테스트: npm run test:mental-health (12개).

암호화 격리/변조, 동의·입력 검증, 보고서 범위와 XSS, 요청 크기·출처, AI 미설정시 외부 전송 차단 및 오류 비노출을 검사한다. 실제 Gemini 응답 품질과 실제 Redis 배포 설정은 유효한 운영 설정에서 별도 확인해야 한다.

2026-10-30 구현 검증 결과:

- 기존 기능 포함 자동 테스트 67개 통과, 프로덕션 빌드 통과.
- 헤드리스 Chrome 데스크톱/390px 모바일에서 기분 입력→암호화 저장→새로고침 복원, 사고기록, 활동 완료·회고, 보고서 다운로드, 삭제 확인. 브라우저 실행 오류와 모바일 가로 넘침 없음.
- 로컬 서버의 실제 API와 가상 Redis 전송 계층을 사용하여 인증·출처·계정 격리·암호문 저장·삭제 후 오래된 저장 거부 확인. 운영 Redis에 연결한 검증은 아님.
- AI 연결 전 비활성화 상태 및 외부 전송 차단 확인. 브라우저에 가상 AI 응답을 제공하여 동의 후 대화 표시, 보고서 분석 표시, 전송 데이터 범위도 확인. 실제 AI의 임상적 적합성이나 상담 효과를 검증한 것은 아님.
- 보안 검사에서 확인한 기존 의존성 취약점에 대응해 Next.js/eslint-config-next 16.4.3, Zod 4.6.7 및 잠금 파일의 undici/source-map-js를 갱신. 최종 npm audit 취약점 0건. 이는 모든 보안 위험이 없다는 의미는 아님.
- 순간 도움 추가 후 기능 테스트 12개, 빌드, 변경 코드 ESLint 통과. 브라우저에서 저장소 응답을 지연시켜도 짧은 안내가 동작함을 확인했고, 가상 AI로 이번 상황만 전송·입력 유지·요청 중단·중복 없는 기록 갱신·보고서 반영·전체 삭제 시 초기화까지 확인했다. 실제 모델 응답 품질은 별도 검증 대상이다.

## 다음 단계 제안

1. 전문가와 함께 상담 예시·위기 및 학대 대응·반복 안심 요구 시나리오를 평가한다.
2. 사용자가 직접 선택한 자료만 넣는 '전문가 상담 준비' 요약을 확장한다.
3. 명시적 동의 후 기기 잠금/별도 기록 잠금과 짧은 자동 보관 기간 선택을 추가한다.
4. 알림은 별도 동의가 있을 때만 도입하고 잠금 화면에 상담·감정 내용을 표시하지 않는다.
