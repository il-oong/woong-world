# 청약 기능 사용·연결 안내

## 사용 흐름

상단 **청약** → 큰 월간 달력 → 추천 카드 → 공고 상세입니다. 날짜를 누르면 해당 날짜의 공고만 아래에 표시됩니다. 카드와 달력의 공고명은 같은 상세 화면으로 연결됩니다.

**내 정보 등록**에서 자금, 직장 주소, 면적·방, 선호 시설, 통장·무주택 조건과 다섯 능력치 중요도를 저장합니다. 금액 입력 단위는 만원, 내부 저장·공고 편집 단위는 원입니다. 미입력은 0원과 구분합니다. 본인 로그인으로만 저장·조회하며 삭제 시 관심 목록과 교통 결과도 지웁니다.

관리자는 `/housing/manage`에서 청약홈 APT 링크를 가져오거나, 공고문 텍스트를 붙여넣어 AI 초안을 만들 수 있습니다. 초안을 원문과 대조하고 체크한 뒤 공개합니다. 코드 편집 없이 주택형·일정·납부금·요약·평면도·위치·근거를 수정할 수 있습니다. 같은 공고번호로 수정하면 변경 설명이 필수이며 상세 화면에 표시됩니다.

공개 APT 기본정보는 GitHub Actions가 한국시간 매일 오전 11:17에 공식 API로 조회해 `src/data/housing-feed.json`을 갱신합니다. 공개 저장소의 표준 GitHub Actions 실행과 기존 Vercel Git 배포를 이용하며 Vercel Cron이나 유료 요금제는 필요하지 않습니다. GitHub 예약 실행은 지연될 수 있어 화면에 실제 갱신일을 표시합니다. API 오류·자료 누락 시 작업이 실패하고 이전 자료를 유지합니다. 최근 45일 모집공고를 갱신하며 APT 이외 주택 종류는 현재 자동 수집 범위가 아닙니다. 공개 데이터에서 확인되지 않는 통장·전매제한·평면도 등은 미확인으로 표시하고, 공식 기본정보가 기존 분석과 달라지면 종전 분석을 보류합니다. 관리자가 저장한 공고 수정본은 자동 자료보다 우선합니다.

## 서비스 설정

기존 로그인과 Redis 설정을 재사용합니다. 키를 소스 코드나 공고 편집기에 넣지 말고 배포 환경의 비밀 설정에 넣습니다.

| 환경 변수 | 용도 | 없을 때 |
|---|---|---|
| `SESSION_SECRET`, Google OAuth 설정 | 기존 로그인 | 개인 정보 저장 불가 |
| `ADMIN_EMAIL` 또는 기존 관리자 목록 | 공고 등록 권한 | 일반 사용자는 공고 편집 불가 |
| `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` | 공고·개인정보 저장 (기존 KV 별칭 지원) | 연결 안내 표시 |
| `APPLYHOME_SERVICE_KEY` | 공공데이터포털 청약홈 분양정보 조회 서비스의 디코딩된 키. GitHub 저장소의 Actions secret에 등록하고 관리자 가져오기에도 쓰려면 Vercel 환경 변수에도 등록 | 일일 갱신·관리자 API 가져오기 불가 |
| `GEMINI_API_KEY` | 공고문 사전 분석 (기존 설정 재사용) | 직접 요약 입력 가능 |
| `KAKAO_REST_API_KEY` | 공급·직장 주소를 좌표로 변환 | 확인한 좌표 직접 입력·지도 링크 사용 |
| `ODSAY_API_KEY` | 대중교통 경로 조회 | 교통 점수 미확인 |

연결 자료: [청약홈 API](https://www.data.go.kr/data/15098547/openapi.do), [공식 API 명세](https://infuser.odcloud.kr/api/stages/37000/api-docs), [카카오 주소 검색](https://developers.kakao.com/docs/latest/ko/local/dev-guide#address-coord), [ODsay 가이드](https://lab.odsay.com/guide/guide?platform=web).

무료 [공공데이터포털 청약홈 분양정보 조회 서비스](https://www.data.go.kr/data/15098547/openapi.do) 활용 신청 후 GitHub 저장소 **Settings → Secrets and variables → Actions → New repository secret**에서 `APPLYHOME_SERVICE_KEY`를 설정해야 일일 갱신이 실제 작동합니다. 키는 채팅이나 코드에 붙여넣지 마세요. 설정 뒤 **Actions → 청약 공고 하루 한 번 갱신 → Run workflow**로 첫 실행을 확인하세요. 실제 키를 통한 외부 공급자 응답 검증은 설정 후 필요합니다.

## 실제 공고 등록

사용자가 제공한 링크:

`https://www.applyhome.co.kr/ai/aia/selectAPTLttotPblancDetail.do?houseManageNo=2026000453&pblancNo=2026000453`

이 공고는 2026-09-30 기준 [공식 입주자모집공고문](https://static.applyhome.co.kr/ai/aia/getAtchmnfl.do?houseManageNo=2026000453&pblancNo=2026000453&atchmnflSeqNo=1971127&atchmnflSn=7)의 1·5·6·9·10·25·43쪽 및 [공식 분양 홈페이지](https://xn--hc0bz5m11b1ue95n2zf6zxvzd.com/pages/unit)의 주택형 자료와 대조했습니다. `src/lib/housing/catalog.ts`에 공개 정보로 포함되어 저장소 설정 없이도 `/housing/2026000453`에서 열 수 있습니다. 관리자 편집으로 같은 번호를 저장하면 수정본이 우선하며, 삭제하면 저장소에 삭제 표시가 남습니다.

7개 주택형은 최고층 구간 분양가를 사용합니다. 실제 계약 금액은 동·층에 따라 달라집니다. 계약금 1차는 계약 시, 2차는 계약 후 1개월 내, 잔금은 입주지정일 납부입니다. 정확한 날짜가 없으므로 납부액과 2027~2028년 중도금 날짜는 표시하되 부족액·돈 점수 계산은 보류합니다. 입주는 **2029년 3월 예정**으로, 특정 날짜를 임의로 넣지 않았습니다. 현장 지도는 [공식 홈페이지에서 연결한 카카오맵 단지](https://place.map.kakao.com/328464023)이며 견본주택 주소와 분리했습니다. 단지 좌표가 검증되기 전까지 대중교통 자동 조회는 보류합니다.

이후 다른 공고는 관리자 화면에서 청약홈 링크를 가져와 기본정보를 만들고, 공식 공고문을 페이지 번호와 대조해 공개합니다. AI 분석 결과는 초안이며 원문 확인 후 게시합니다.

청약홈 기본정보 API의 `SUPLY_AR`는 공급면적이므로 전용면적으로 사용하지 않습니다. `LTTOT_TOP_AMOUNT`는 만원 단위 최고 공급금액으로 가져오며, 층별 실제 금액은 원문 대조 후 수정해야 합니다. 임대 공고 자동 가져오기는 지원하지 않지만 직접 입력·공고문 분석·보증금/월세 계산은 가능합니다.

## 알림 연결

기존 알림 발송 코드는 이 저장소에서 확인되지 않았습니다. 새 알림의 클릭 주소는 아래 형식으로 연결할 수 있습니다.

`/housing/open?houseManageNo=2026000453&pblancNo=2026000453`

등록된 공고면 상세페이지로 이동하고, 분석 전이면 공식 청약홈 원문 링크를 보여줍니다. 외부 사이트에서 발생한 알림의 주소를 이 앱에서 변경할 수는 없습니다. 알림 발송 시스템에 위 주소를 적용해야 합니다.

## 점수와 계산의 범위

- 돈: 시점별 최대 자금 부족 비율과 월 부담 한도를 계산합니다. 전체 납부액과 본인 자금 정보가 있어야 점수가 나옵니다. 저축은 오늘부터 각 납부일까지의 완료된 달 수로 계산합니다.
- 교통: 내 직장까지의 일반 대중교통 경로 시간·환승·도보를 계산합니다. 실시간 혼잡이나 시간표를 지정한 출근 예측이 아닙니다. 도시 간 일부 경로만 오는 결과는 점수에 사용하지 않습니다. 사용자가 조회할 때 갱신하며 일자·직장·단지 좌표가 바뀌면 기존 결과를 쓰지 않습니다.
- 입지: 선택한 시설들의 확인된 거리(180일 이내)를 사용합니다. 직선거리 자료는 보행시간으로 표시하지 않습니다.
- 컨디션: 전용면적·방 수와 희망 조건의 적합도입니다. 층·향·마감 상태의 자동 평가는 포함하지 않습니다.
- 투자: 180일 이내 주변 비교가격 대비 공급가격 지표입니다. 수익률 예측이 아니며, 임대에서는 제외합니다. 전매제한은 별도 필수정보로 보여줍니다.
- 0보다 큰 비중의 모든 항목을 확인해야 종합점수와 추천 순위를 표시합니다. 조건 불충족은 추천 순위에서 제외하고 전체 목록에서 이유를 보여줍니다. 부족한 자료를 임의의 평균 점수로 채우지 않습니다.
- 자금 시뮬레이션은 예상 대출을 마지막 납부 시점에 한 번만 더합니다. 중도금 대출 전환, 승인 한도, 세금·옵션·이사비 등은 자동 계산하지 않습니다. 본인 입력값을 이용한 사전 검토입니다.
- 통장 보유·가입 기간·예치금·무주택 조건만 구조화된 공고 기준과 자동 대조합니다. 소득·자산·지역 우선공급·세대 조건·실제 1순위·당첨 가능성은 확정하지 않습니다.

## 운영 전 확인과 검증

`npm run test:housing`, `npx eslint src/lib/housing src/components/Housing src/app/housing src/app/api/housing`, `npm run build`로 핵심 계산·입력 검증과 빌드를 확인합니다. 테스트용 공고는 `tests/`에만 있으며 실제 공고 1건은 위 공개 카탈로그에 명시적으로 포함했습니다.

운영 환경에서는 첫 일일 실행 후 실제 API 금액·날짜와 공고 원문이 일치하는지 확인하세요. APT 이외 공고 자동 수집, 정정공고 원문 자동 해석, 청약 일정 푸시 발송은 별도 연결 범위입니다.
