# 도면 양식 규격 (판교 푸르지오 그랑블 시공도면 기준)

원본: `2026.04.10_*.pdf` (42장, A3 가로 420×297mm, 알PDF 출력, 글자는 외곽선 변환). 수치는 PDF 벡터를 직접 측정한 값이며 코드 상수는 `src/lib/drawing/template.ts`.

## 시트 종류
1. **상세도 시트** (대부분): TOP VIEW / NOTE / FRONT VIEW_DOOR / FRONT VIEW_BODY(또는 SIDE VIEW) 4분할 + 하단 타이틀블록. 축척 1/30.
2. **평면도 시트** (p3 드레스룸, p17·p23 자녀침실, p30 주방): 얇은 바깥 테두리만, 좌하단 2줄 제목, 우하단 `SCALE 1/20`(주방은 1/30).
3. **키플랜 삽입 시트** (p18~): 상세도 시트 왼쪽 위에 작은 위치도 박스 + 빨간 화살표.

## 치수 표현
- 눈금은 화살표가 아닌 **45° 사선**(길이 1.62mm), 치수선은 눈금 밖으로 1.2mm 연장.
- 보조선: 물체에서 1.2mm 띄워 시작, 치수선 너머 1.2mm 연장.
- 치수선 열 간격 7.5mm, 가장 가까운 열은 물체에서 6.6mm. 큰 총치수가 바깥, 분할치수가 안쪽.
- 숫자는 선 위 중앙(선과 0.87mm 간격), 세로 치수는 90° 회전. 쉼표 천단위, 단위 표기 없음.
- 치수선·눈금은 연회색이라 도면 윤곽(검정 굵은선)과 위계가 분명함.

## 틀 위치 (상세도 시트, mm)
바깥 테두리 (4.53, 3.2)–(415.54, 293.86) / 안쪽 프레임 (8.93, 7.61)–(411.14, 289.46) / 세로 구분 x=210.02 / 가로 구분 y=18.02, 114.29, 124.23 / NOTE 줄 y=30.1, 42.1, 54.2 / 타이틀블록 상단 y=267.19 / 입력줄 y=275.5, 285.8.

## 아직 측정하지 않은 것 (이어서 할 일)

- 파랑 구름·인출선의 정확한 형상, 키플랜 박스 크기
- 라벨 바(SITE LOCATION 등) 정확한 크기·글자 크기
- 4~42p 변형(레이어 배치, 2열 NOTE, 확대 원 상세) 목록화
